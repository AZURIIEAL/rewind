# Assets

Source art:

- `logo.png` — full brand lockup (mark + "REWIND / DEVELOPER TOOL" wordmark)
- `rewind-file-logo.png` — the `.rewind` file glyph

Everything below is derived from those two files.

| Path | Contents | Use |
|---|---|---|
| `icons/mark-{16,32,48,64,128,256,512}.png` | Chevron mark only, square, dark card background | App/window icons |
| `icons/favicon.ico` | Multi-size (16/32/48/64) favicon bundle | Docs site / browser tab |
| `icons/file-icon-{16,32,48,64,128,256,512}.png` | `.rewind` file glyph, square | File-type icon (e.g. VS Code / OS file association) |
| `nuget/icon-{128,256}.png` | Same mark artwork, NuGet-sized | Wired into `PackageIcon` in `Rewind.Core`, `Rewind.Cli`, `Rewind.AspNetCore` csproj files |
| `social/github-social-preview-1280x640.png` | Full lockup, 2:1 crop | Upload manually under repo Settings → Social preview (no API for this) |
| `readme/banner-960.png` | Full lockup, resized | Embedded at the top of `README.md` |
| `icons/rewind-file.ico` | Multi-size (16/32/48/64/128/256) `.ico`, built from `file-icon-*.png` via `magick` | Windows `.rewind` file-type icon |
| `file-association/windows/*.ps1` | PowerShell scripts | Register/unregister the Windows Explorer icon for `.rewind` (per-user, `HKCU`, no admin) |
| `file-association/macos/*.sh` | Shell scripts (macOS only) | Build a minimal helper app bundle + `.icns` and register/unregister it with Launch Services so Finder shows the icon |
| `file-association/linux/*.sh` | Shell scripts | Register `.rewind` as a shared-mime-info type and install the icon into `~/.local/share/icons/hicolor` for GNOME/KDE/etc. file managers |
| `file-association/vscode-icons/file_type_rewind.png` + `settings-snippet.json` | Copy of `file-icon-128.png` renamed to the [vscode-icons](https://github.com/vscode-icons/vscode-icons) custom-icon convention, plus a settings.json snippet | VS Code Explorer icon for `.rewind`, via the vscode-icons extension's custom associations |
| `file-association/vscode-material-icon-theme/*.sh` | Shell scripts | Patch an installed [Material Icon Theme](https://marketplace.visualstudio.com/items?itemName=PKief.material-icon-theme) extension directly, since it has no settings-based way to use a custom icon image |

See the top-level `README.md`'s "File icon for `.rewind` files" section for setup instructions for each of the above.

All derived files were generated by resizing/cropping the two source PNGs (nearest bounding-box crop + bilinear resize) — no new artwork was drawn. The mark's native resolution in the source is only ~300x300px, so `mark-512.png` is a mild upscale; if a crisper large icon is needed later, it should come from the original vector/design source rather than this raster pipeline.
